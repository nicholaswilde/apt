Client Configuration

Configure your Debian or Ubuntu based system to install packages directly from this repository.

1 Download Repository Signing Key

Install the repository's ASCII-armored GPG public key into your system's keyring directory:

bash 
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://nicholaswilde.io/apt/public.key | sudo gpg --dearmor -o /etc/apt/keyrings/nicholaswilde-apt.gpg
sudo chmod a+r /etc/apt/keyrings/nicholaswilde-apt.gpg

2 Add Repository Source

Add the repository to your APT sources. Choose either the modern Deb822 format (Debian 12+ / Ubuntu 22.04+) or traditional one-line format:

Option A: Modern Deb822 Format (Recommended)

/etc/apt/sources.list.d/nicholaswilde.sources 
sudo tee /etc/apt/sources.list.d/nicholaswilde.sources << 'EOF'
Types: deb
URIs: https://nicholaswilde.io/apt
Suites: stable
Components: main
Signed-By: /etc/apt/keyrings/nicholaswilde-apt.gpg
EOF

Option B: Traditional One-Line Format

/etc/apt/sources.list.d/nicholaswilde-apt.list 
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/nicholaswilde-apt.gpg] https://nicholaswilde.io/apt stable main" | sudo tee /etc/apt/sources.list.d/nicholaswilde-apt.list

3 Update & Install

Refresh package indexes and install desired packages:

bash 
sudo apt update
sudo apt install <package-name>
